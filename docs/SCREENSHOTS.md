# Скриншоты проектов

Исходники можно хранить на Google Drive. В Git добавляются подготовленные публичные версии: PNG или WebP, обычно 1200–1600 пикселей по ширине. Большие видео и аудио остаются во внешнем хранилище.

Приоритеты:

1. APPLI: общий экран, планирование, финансы, подтверждение операции AI. Использовать демо-данные и скрыть личные сведения.
2. Учебный сайт: выбор режима, вопрос с объяснением, English Practice.
3. Среда агентов: схема процесса и аккуратный пример задачи/ревью без секретов. Схема подписывается как схема, а не скриншот.
4. Лаборатория Microsoft: схема окружения и проверяемые результаты настройки с обезличенными данными.

Путь, например: `public/images/appli/planning.webp`.

В `content/projects.json` у проекта:

```json
"images": [
  {
    "src": "/images/appli/planning.webp",
    "alt": "Widok planowania w aplikacji APPLI",
    "caption": "Planowanie w APPLI — dane demonstracyjne."
  }
]
```

Первое изображение заменяет схему в карточке. Остальные доступны в подробностях. Нажатие открывает увеличенное изображение; Escape закрывает просмотр. Пустой список показывает подписанную схему и не создаёт пустых галерей.

Не публиковать экран авторизации, аккаунт облака, ключи, токены, личные расходы, пользовательские email или чужие записи без разрешения. Не создавать искусственные изображения интерфейса и не выдавать их за работающий продукт.
