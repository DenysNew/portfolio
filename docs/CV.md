# Обновление CV

Первая версия использует уже проверенный PDF AI / Automation. Сборка сайта копирует его из `public/cv/`; она не меняет содержание документа.

Общие факты о проектах находятся в `content/projects.json`. Короткие формулировки и набор выбранных проектов для CV хранятся отдельно в `content/cv/ai.json`, поскольку полное описание сайта не должно автоматически переноситься в резюме.

Порядок обновления:

1. Проверить изменившийся факт и обновить описание проекта.
2. Если изменение важно для работодателя, обновить короткую формулировку CV.
3. Сформировать документ и проверить содержание, переносы и кликабельные ссылки.
4. Сохранить отправляемую работодателю копию с датой; заменить текущий PDF на сайте только после проверки.

Автоматический генератор PDF из коротких описаний — отдельный следующий этап. Он не должен самостоятельно менять выбранное направление, уровень навыков или статус сертификатов.
